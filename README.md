# 🎯 TMDB Movie App

A production-ready movie streaming UI built with React and TMDB API.

## ⭐ Features
- Popular Movies
- Movie Details Page
- Search with Debounce
- Favorites (Persistent)
- Lazy Loading & Code Splitting
- Feature-based Architecture

## 🛠 Tech Stack
- React (Hooks)
- React Router
- Context API
- Tailwind CSS
- TMDB API
- Vite

## ⚡ Performance
- Debounced search
- Memoized components
- Lazy loaded routes
